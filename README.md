# SkillBridge

SkillBridge is a resume and job description matching platform designed to help job seekers understand how well their resumes match a particular job role.

## Features

- Resume and job description analysis
- Resume-job compatibility evaluation
- Skills matching and gap identification
- Analysis reports to help candidates improve their resumes
